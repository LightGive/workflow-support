# FlowChartImporter

Excelで作成した業務フロー図(図形+矢印)を解析し、JSONファイルと、フロー内容を要約したCSVファイルを作成するツールです。Excelアプリケーションのインストールは不要です。

## 使い方

```
FlowChartImporter.Cli.exe <Excelファイル> <シート名> [オプション]
```

例:

```
FlowChartImporter.Cli.exe 業務フロー.xlsx Sheet1 --csv 業務フロー.csv --output 業務フロー.json
```

シート名が分からない場合は `--list-sheets` で一覧を確認できます。

```
FlowChartImporter.Cli.exe 業務フロー.xlsx --list-sheets
```

## オプション

| オプション | 説明 |
|---|---|
| `--settings <パス>` | 設定ファイルのパス(省略時: このexeと同じフォルダの `settings.json`) |
| `--output <パス>` | JSONファイルの出力先パス(省略時: JSONは出力せず、ノード数・エッジ数のみ表示) |
| `--csv <パス>` | 要約CSVファイルの出力先パス(省略時: CSV出力なし) |
| `--min-row <行番号>` | この行番号(1始まり)より上の内容を無視する |
| `--ignore-actor <実施主体名>` | 一番左の列に書かれた実施主体名がこれと一致する行を無視する |
| `--list-sheets` | シート名の一覧を表示して終了 |
| `--help` | ヘルプを表示して終了 |

実行時の警告(接続の重複、フローに繋がっていない図形など)は画面に表示されます。エラーが出ていなくても、内容に問題がありそうな場合は警告を確認してください。

## 設定ファイル(settings.json)

初回実行時、指定した場所に無ければ自動で作成されます。よく調整する項目は以下の通りです。

| 項目 | 説明 |
|---|---|
| `nodeNumberFormat` | 処理名の表示フォーマット。`{no}` が番号に置換される(例: `"A-{no}"` → `A-10`) |
| `branchLabelSearchRadiusPoints` | 分岐(ひし形)の近くにあるYES/NOラベル、書類シェイプ(関連ファイル)、「[」図形(備考)を探す範囲。反映されない場合はこの値を広げる |
| `connectionTolerancePoints` | 矢印と図形の接続判定の許容誤差。矢印が繋がっていないと判定される場合はこの値を広げる |
| `categoryNameStart` / `categoryNameEnd` / `categoryNameBranch` / `categoryNameProcess` / `categoryNameCall` | CSVの「種類」列に表示する名称 |

## CSVの列

| 列 | 内容 |
|---|---|
| 処理名 | 番号付きの表示名 |
| 種類 | 開始/終了/分岐/処理/呼び出し |
| 分岐ルート | そのノードに至るまでに必ず通った分岐のYES/NO |
| 実施主体 | 図形が置かれている列の見出し(部署・システム・他社等) |
| 内容 | 図形内のテキスト |
| 備考 | 関連ファイル、近くの「[」図形の内容 |

## 図面を作る際の注意点

- **YES/NOラベル**として認識されるのは、分岐(ひし形)の近くに置いた「テキストボックス」または「枠線なしの長方形」だけです。楕円や枠線付きの長方形に書いても認識されません。
- YES/NOの文字は完全一致(大文字小文字・全角半角は区別しない)でのみ認識されます。「Yes」を「YWS」のように誤入力すると認識されず、矢印自体に書いた場合はそのままCSVに誤字として出力されます。
- 矢印自体にテキストを書いた場合はそれが優先され、YES/NO判定は行われません。
- 分岐(ひし形)から出る矢印はYES・NOが1本ずつ対になっている想定です。片方しか認識できなかった場合は警告が表示され、その分岐のラベルは分岐ルート(CSVの3列目)には使われません。
- 点線の矢印は「データのやり取り」として扱われ、フローの接続としては使われません。
- 矢印が1本も繋がっていない図形は、出力対象から除外され警告に表示されます。
- 書類シェイプ(関連ファイル)や「[」図形(備考)は、対象の図形と重なっていなくても、中心が近ければ最も近いノードに自動的に紐づきます。離れすぎていると紐づかないので、その場合は`branchLabelSearchRadiusPoints`を広げてください。
