# FlowChartViewer

`FlowChartImporter.Cli`の`--output`で出力したJSONファイルを、ブラウザ上でフロー図として可視化するツールです。ビルドやインストールは不要です。

## 使い方

1. `index.html`をブラウザ(Chrome/Edge等)で開く
   - ダブルクリックで開くか、ブラウザに直接ドラッグ&ドロップしてください
2. 画面上部の「JSONファイルを開く」からJSONファイルを選択する、またはJSONファイルを画面にドラッグ&ドロップする

サーバーやネットワーク通信は一切使用せず、ブラウザ内で完結して動作します。JSONファイルの内容もどこにも送信されません。

## できること

- ノードを図形タイプ(処理/分岐/開始/終了/呼び出し/書類/入出力)ごとに色分けして表示
- 矢印(エッジ)を表示。ラベル(Y/N等)があれば矢印上に表示
- 同じノード間に複数の矢印がある場合は、重ならないように曲げて表示(重複エッジの目視確認に有用)
- マウスホイールでズーム、ドラッグでパン、右上のボタンで拡大・縮小・全体表示
- ノードをクリックすると、右側パネルに内容・実施主体・関連ファイル・備考を表示
- 右側の「ノード一覧」から該当ノードへジャンプ

## レイアウトについて

Excel上の元の座標は使わず、以下のルールで自動的にレイアウトします(スイムレーン形式)。

- **縦方向**: 実施主体(`actors`の先頭要素)ごとにレーンを分けます。レーンの並び順は、元のシート上でその実施主体が上にあったものほど上になります。実施主体が未判定のノードは最下段の「(未分類)」レーンにまとめます
- **横方向**: 採番番号(`number`)の小さい順に左から並びます

そのため、1つの図形が複数の実施主体にまたがっている場合(`actors`が2件以上)でも、表示上は先頭の実施主体のレーンにのみ配置されます(残りの実施主体はノードクリック時の詳細パネルで確認できます)。
