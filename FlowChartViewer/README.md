# FlowChartViewer

`FlowChartImporter.Cli`の`--output`で出力したJSONファイルを、ブラウザ上でフロー図として可視化するツールです。ビルドやインストールは不要です。

## 使い方

1. `index.html`をブラウザ(Chrome/Edge等)で開く
   - ダブルクリックで開くか、ブラウザに直接ドラッグ&ドロップしてください
2. 画面上部の「JSONファイルを開く」からJSONファイルを選択する、またはJSONファイルを画面にドラッグ&ドロップする

サーバーやネットワーク通信は一切使用せず、ブラウザ内で完結して動作します。JSONファイルの内容もどこにも送信されません。

## できること

- ノードを図形タイプ(処理/分岐/開始/終了/呼び出し/書類/入出力)ごとに色分けして表示
- 矢印(エッジ)を、Mermaidのフロー図のような滑らかな曲線で表示。ラベル(Y/N等)があれば曲線上に表示
- 同じノード間に複数の矢印がある場合は、重ならないように曲げて表示(重複エッジの目視確認に有用)
- マウスホイールでズーム、ドラッグでパン、右上のボタンで拡大・縮小・全体表示
- ノードをクリックすると、右側パネルに内容・実施主体・関連ファイル・備考を表示
- 右側の「ノード一覧」から該当ノードへジャンプ

## レイアウトについて

Excel上の元の座標は使わず、Mermaid(内部的にはdagre等)のようなグラフ構造からの自動整列と、実施主体ごとのスイムレーンを組み合わせて自動的にレイアウトします。

- **縦方向(レーン)**: 実施主体(`actors`の先頭要素)ごとにレーンを分けます。レーンの並び順は、元のシート上でその実施主体が上にあったものほど上になります。実施主体が未判定のノードは最下段の「(未分類)」レーンにまとめます
- **横方向(階層)**: 採番番号ではなく、矢印のつながり(グラフ構造)から各ノードの階層を自動計算し、階層が小さいほど左から並びます。分岐からの再実行ループなどの「手前に戻る矢印」は自動検出し、階層計算には使いません
- **レーン内の並び順**: つながっている相手ノードに近づくよう自動的に並び順を調整し(重心法)、関連ノード同士が隣接しやすくします。1つの実施主体に多数のノードがある場合、全ノードが一直線に並ぶと間のノードを飛び越すエッジが重なって見づらくなるため、レーン内を複数段に自動分割しますが、機械的にジグザグさせるのではなく、分岐や合流のない単純な経路はできるだけ同じ段(=一直線)のまま、実際にずらす必要がある箇所だけ段をずらすため、できるだけ中央ぞろえに近い見た目になります

そのため、1つの図形が複数の実施主体にまたがっている場合(`actors`が2件以上)でも、表示上は先頭の実施主体のレーンにのみ配置されます(残りの実施主体はノードクリック時の詳細パネルで確認できます)。矢印は曲線で描画され、他の図形やエッジとできるだけ重ならないようにしていますが、複雑なフローでは完全に交差を避けられない場合があります。
